# 🛒 BazarDor — বাজার দর

**BazarDor** is a web application designed to help users check product prices, compare market prices, and make better shopping decisions. It provides a simple and user-friendly interface for exploring products and staying informed about market prices.

## ✨ Key Features

- **Product Price Tracking:** Explore product prices and stay updated on market rates.
- **Price Comparison:** Compare prices to make informed purchasing decisions.
- **Category-Based Browsing:** Find products easily by browsing different categories.
- **User Authentication:** Sign up and sign in to access account-related features.
- **Responsive Design:** Enjoy a smooth browsing experience on desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- **Next.js** — React framework for building the application.
- **React.js** — For creating interactive user interfaces.
- **Tailwind CSS** — For responsive styling and UI design.
- **Better Auth** — For user authentication.
- **MongoDB** — For database management.
- **Lucide React** — For interface icons.
- **React Toastify** — For success and error notifications.

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js and npm installed on your computer.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd bazardor
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Configure the required environment variables in a `.env` file.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open [http://localhost:3000](http://localhost:3000) in your browser.

The goal of BazarDor is to make market price information easier to access and help people make smarter shopping decisions through a simple and accessible web application.
